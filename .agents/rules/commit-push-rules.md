# Rules: Commit + Push (NewKet)

- Toujours demander/valider un message de commit si le scope est ambigu.
- Si le diff est massif ou suspect (build outputs, logs, node_modules), s'arreter et demander confirmation.
- Prefere un message de commit en anglais court (ex: `fix: ...`, `chore: ...`) sauf si l'utilisateur insiste en francais.
- Ne pas utiliser `--force` sans demande explicite.
